# Evolve Training V0.8 — Dashboard premium

Cette version rapproche l'accueil de la maquette validée :
- logo centré
- menu latéral à gauche
- notifications à droite
- bloc récupération
- grande carte séance du jour avec visuel athlète de dos
- aperçu des 3 premiers exercices
- prochaine séance
- suivi de routine 7 jours
- cartes sommeil / fatigue / courbatures / motivation / douleur
- dernière performance et 1RM estimé
- navigation Accueil / Programme / Stats / Profil

## Menu dynamique
La structure est prête pour afficher/masquer des fonctionnalités selon les services achetés. Les droits d'achat ne sont pas encore connectés au backend : ce sera une étape dédiée.

## Visuels homme/femme
Le dashboard sélectionne automatiquement le visuel homme ou femme selon le profil de l’athlète.
